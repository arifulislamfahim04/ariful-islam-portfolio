# Your first CMS edit

1. Open https://app.pagescms.org/ and sign in with GitHub.
2. If the new repository is missing, open the Pages CMS GitHub App settings and include **ariful-islam-portfolio**. Keep the old repository selected if you want its CMS to continue working.
3. Select **arifulislamfahim04 / ariful-islam-portfolio**, branch **main**.
4. Open **Profile, résumé & homepage** to edit your profile facts, contacts, portrait, CV and statistics. Use **Homepage design & identity tag** for headline and design text.
5. Make one small text change and save. You do not need to edit code or copy files.
6. Check GitHub → Actions → **Publish portfolio content**. When it is green, refresh the live site. A failed build leaves the last successful version live.

## Common tasks

- Replace CV: upload/select the PDF in the Profile résumé field, then save. Uploading a file alone does not change the selected CV.
- Add a photo: open Gallery, create a moment, choose an image, enter a title and enable Show on website. Enable homepage preview separately if desired.
- Add a project or blog: create an entry, add its title/summary/body and enable Show on website.
- Hide something: disable Show on website. This hides the website entry, but not its file in this public repository.
- Adjust footer/navigation/theme/motion: use their shared CMS settings. Do not rename entry files unless you want their URLs to change.

Content changes affect this new site only. Keep `Site settings → Website URL` pointed at the new GitHub Pages address. If an update appears missing, check that you selected this repository and **main**, and that the latest publish workflow passed.
